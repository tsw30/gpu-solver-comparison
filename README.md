# GPU Solver Comparison

Repository for storing scripts and setup files used to create CFD test cases,
convert them to different solver formats, and run comparisons.

## Directory Structure

```
gpu-solver-comparison/
├── case-definitions/   Test case descriptions
├── solvers/            Solver-specific setup files
├── scripts/            Conversion and utility scripts
├── tests/              Tests for scripts and comparisons
├── results/            Comparison outputs and logs
└── docs/               Notes and references
```
